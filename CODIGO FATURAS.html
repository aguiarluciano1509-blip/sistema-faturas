Estrutura básica de um formulário de fatura

Aqui estão os principais campos que você pode incluir:

1. Cabeçalho

  • Logo da empresa (opcional)

  • Título: "Fatura" ou "Invoice"

  • Número da fatura

  • Data de emissão

  • Data de vencimento

2. Informações do emissor (sua empresa)

  • Nome da empresa

  • Endereço

  • Telefone / e-mail

  • CNPJ ou CPF (se aplicável)

3. Informações do cliente

  • Nome completo ou razão social

  • Endereço

  • Telefone / e-mail

  • CPF ou CNPJ

4. Tabela de itens/serviços

DescriçãoQuantidadePreço UnitárioTotal
Produto/Serviço A2R$ 100,00R$ 200,00
Produto/Serviço B1R$ 150,00R$ 150,00

5. Totais

  • Subtotal

  • Impostos (se houver)

  • Descontos (se houver)

  • Total Geral

6. Observações

  • Campo para observações adicionais (ex.: condições de pagamento, agradecimento, instruções).

7. Rodapé

  • Informações bancárias ou meios de pagamento

  • Termos e condições (opcional)

  • Você pode personalizar o nome do arquivo no doc.save("fatura.pdf").

// Carrega o número da fatura ao abrir a página
function carregarNumeroFatura() {
  let numero = localStorage.getItem("numeroFatura");

  if (!numero) {
    numero = 1; // começa do 1 se não existir
  }

  document.getElementById("numeroFatura").innerText = numero.toString().padStart(3, "0");
}

// Incrementa o número após gerar o PDF
function incrementarNumeroFatura() {
  let numero = localStorage.getItem("numeroFatura");

  if (!numero) {
    numero = 1;
  } else {
    numero = parseInt(numero) + 1;
  }

  localStorage.setItem("numeroFatura", numero);
}

✅ 3. Ajuste na função de gerar PDF

async function gerarPDF() {
  const { jsPDF } = window.jspdf;

      // Depois de gerar o PDF, incrementa o número
      incrementarNumeroFatura();
      carregarNumeroFatura();
    },
    x: 10,
    y: 10
  });
}

window.onload = carregarNumeroFatura;
